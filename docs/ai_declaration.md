# Declaration of AI Use

This declaration responds to the assignment's requirement to state whether AI tools were used,
what they were used for, and approximately how much of the code was generated by AI.

**Tool.** Claude Code (Anthropic), model Claude Opus 5.5, used in November 2026.

**Share of AI-generated code.** Approximately 100 % of the code in this repository was generated with
AI assistance. This covers the algorithm implementations, data loading and validation, experiment,
table and plotting scripts, audit scripts and automated tests.

**Marking.** Every AI-generated source file starts with the line
`# AI attribution: generated with Claude Code (Anthropic, Claude Opus 5.5).` The empty package files
(`__init__.py` without content) contain no code.

**What the AI was used for**
- Implementing the Bees Algorithm (Problem 1) and the three Evolution Strategies (Problem 2) according
  to the assignment specification.
- Writing automated tests and independent audit scripts that re-check the saved results.
- Running the experiments and generating the tables and figures from the saved results.
- Writing the repository documentation (README files, implementation notes, requirements checklist).
- Reviewing the implementation and results, and carrying out the supplementary diagnostic analyses.
- Explaining algorithms and code to the student as study material.

**Role of the student**
- Defined the requirements and quality standards.
- Confirmed the required cases against the original assignment PDF.
- Decided when to proceed between stages.
- Approved or rejected methodological choices (for example the parameter pilots and the
  post-hoc analyses).
- Reviewed the code and results.
- Is the author of the written report.

**How AI output was checked.** AI-generated code was not accepted on trust. Its correctness was
checked with:
- automated tests, including comparisons with published reference values (TSPLIB optimal tour
  lengths, SFU reference implementations, the assignment's port1 checkpoint);
- deliberately planted errors, to confirm that the tests detect them;
- independent audit scripts that share no code with the implementation;
- reproduction of all experiments from a clean copy of the repository.
